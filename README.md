# Alentejano Analista — screener com P/E ao vivo

Site pronto para o Render. Não precisa de chave de API.

O rácio P/E é o último preço a dividir pelo lucro dos últimos 12 meses (Yahoo Finance, gratuito). Atualiza sozinho a cada 30 segundos.

## Render

1. Novo **Web Service**, repositório ou upload deste projeto.
2. Runtime: **Node**.
3. Build command: `npm install`
4. Start command: `npm start`
5. Node 20 ou superior (recomendado 22).

O Render define a variável `PORT`. O servidor escuta em `0.0.0.0`.

## Local

```bash
npm start
```

Abre `http://localhost:3000`.
